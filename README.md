# IRONMAN Vichy 2027

תוכנית אימונים בת 52 שבועות ושני לוחות שנה שמתעדכנים אוטומטית.

| מה | כתובת |
|---|---|
| דף התוכנית המלא | `https://<owner>.github.io/<repo>/` |
| לוח אימונים (subscribe) | `https://<owner>.github.io/<repo>/vichy.ics` |
| מצב הים בתל אביב (subscribe) | `https://<owner>.github.io/<repo>/waves.ics` |

## איך נרשמים ללוח באייפון

הגדרות ← אפליקציות ← לוח שנה ← חשבונות ← הוסף חשבון ← אחר ← **הוסף לוח שנה למנוי** ←
להדביק את הכתובת ← הבא ← שמור.

זו **הרשמה**, לא ייבוא: הטלפון שומר את הכתובת בלבד ומוריד את הקובץ מחדש מעצמו.
כל עדכון של הקובץ כאן מגיע לטלפון בלי לעשות כלום.

## התקנה כאפליקציה בטלפון

לפתוח את כתובת האתר **בספארי** (אייפון) או **בכרום** (אנדרואיד) ←
כפתור השיתוף ← **«הוסף למסך הבית»**.

מקבלים אייקון אמיתי, פתיחה במסך מלא בלי סרגל הדפדפן, ו**עבודה גם בלי אינטרנט** —
הדף נשמר במכשיר בפעם הראשונה שנפתח.

הסימונים נשמרים במכשיר. למעבר בין מכשירים יש «גיבוי לקובץ» ו«שחזור מגיבוי»
בלשונית «אימוני כל שבוע».

## מבנה

```
index.html          דף התוכנית — עצמאי, עובד גם בלי רשת
manifest.webmanifest  הגדרות ההתקנה כאפליקציה
sw.js               service worker · שמירה במכשיר לעבודה לא-מקוונת
icon-*.png          אייקונים למסך הבית
vichy.ics           לוח האימונים · אירוע נפרד לכל אימון
waves.ics           מצב הים · אירוע יומי אחד, 7 ימים קדימה
data/waves-data.json  התחזית הימית האחרונה שנמשכה
tools/genwaves.mjs  מחולל לוח הים
tools/gh.mjs        פרסום ל-GitHub Pages
```

## עדכון ידני

```bash
export GH_TOKEN=…  GH_OWNER=…  GH_REPO=…
node tools/genwaves.mjs data/waves-data.json waves.ics
node tools/gh.mjs push waves.ics
```
